What every pack contains

SlotDocumentWhy it exists
1Agency authorityLets a licensed agency file and collect on the employer's behalf; bounds what it may not do.
2Employment contractThe statutory contract in the local language and English, with the wage, hours and leave the law requires.
3Permit or visa applicationThe employer's application and endorsement, plus the officer's box.
4Compliance declarationThe condition each authority tests hardest: the Turkish 5:1 ratio, the Saudi quota, Bahrainisation.
5Medical / repatriationFitness, accommodation and the return obligation, in one signed record.
Templates are issued for use by a licensed agency. They reproduce the statutory minimum terms; local counsel should still check the current fee schedule and any sector-specific rule before signing.

Using the files

  1. Download the PDF for the destination country and open it in any reader that supports forms — Acrobat, Preview, Chrome or Firefox.
  2. Click each shaded box and type. Bracketed placeholders such as [WORKER_NAME] mark values that repeat across the pack, so use the same spelling throughout.
  3. Check every page, then print A4 single-sided. Signature and stamp areas are deliberately left unshaded.
  4. Open the matching filled sample if you want to see how a completed page reads.

Fees to remember — the employer pays them, not the worker: Serbia NES and visa fees, Türkiye ÇSGB fee, Singapore S$35 and the S$5,000 bond premium, Malaysia levy RM 410 / RM 250 and FOMEMA, Saudi visa and GAMCA fees, Bahrain BHD 195 / BHD 5 / BHD 30.
